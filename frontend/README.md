# Intelligence Hub UI

React 19 + Vite workshop. Pages: Home, Models, Datasets, Resources, Train, Chat, Tasks, Connect, Health.

In development, Vite listens on **port 3000** and proxies `/api`, `/v1`, and `/results` to `http://127.0.0.1:8000`.

```bash
npm install
npm run dev
```

Open **http://localhost:3000** (prefer `localhost` over `127.0.0.1` if the dev server binds IPv6).

Product docs live in the repo root: [docs/GUIDE.md](../docs/GUIDE.md).

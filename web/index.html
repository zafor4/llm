            Safety Guarantees
            
Security Architecture

          

          

            

              
1. Workspace Canonical Containment

              
Every file access is strictly validated against the workspace root. Traversal attacks (e.g. ../../) raise an immediate SecurityError.

            

            

              
2. Untrusted Observation Tagging

              
Subprocess and file outputs are wrapped inside <OBSERVATION> tags, preventing malicious prompt injections from overriding system rules.

            

            

              
3. Subprocess Isolation & Timeouts

              
Generated code executes in separate subprocesses with strict CPU execution timeouts (10 seconds), preventing infinite loops and fork bombs.

            

            

              
4. Destructive Operation Approval Gate

              
Overwriting existing source code files requires approval, defending against catastrophic code deletion.
